Coloque aqui um MP3 por card, com o nome igual ao `id` em `src/data/cards.ts`
(ex.: `agua.mp3`, `ir-com-a-mamae.mp3`).

Pode subir aos poucos: cada card sem MP3 usa a voz do próprio navegador.
Depois de adicionar arquivos, rode `npm run build` para entrarem no cache offline.

Use `scripts/normalizar-audio.sh` para converter e normalizar gravações.
