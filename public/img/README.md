Coloque aqui uma imagem WebP por card, com o nome igual ao `id` em
`src/data/cards.ts` (ex.: `agua.webp`). Sugestão: 512x512, fundo claro.

Pode subir aos poucos: cada card sem imagem mostra o emoji definido no cards.ts.
Depois de adicionar arquivos, rode `npm run build` para entrarem no cache offline.

Prioridade: foto real das pessoas/objetos do dia a dia da criança primeiro
(mamãe, papai, eu, água, banheiro, comer), pictograma ARASAAC para os verbos e
abstratos, sentimentos por último.
